# Blockchain-Based Loan System with AI Verification

## Project Overview

This project proposes a blockchain-based loan system with AI-assisted transaction verification. The system would allow users to borrow money, repay loans, and contribute funds toward loans requested by other users.

## Research and Comparison

The accompanying paper and presentation would examine how lending systems operated historically and how they function in the 21st century. The proposed system would then be compared with existing blockchain-based and traditional non-blockchain lending systems.

## Proposed System

- Money would remain in each user’s account until a loan is issued.
- Each account would have a blockchain document indicating how much of the money in that account does not belong to the account holder.
- The blockchain document would track:
  - Transactions
  - Loan interest
  - Individual contributions
  - Transaction times
  - Borrowers
  - Contributors

## AI Verification

- AI models would be used to verify transactions.
- Multiple verifiers would be required for each transaction.
- Anyone who contributes an API key for verification would receive a portion of the profit from the specific transaction being verified.
- AI would inspect bank statements for individual loans to confirm that recorded transactions are consistent.

## Loans, Contributions, and Interest

- Borrowers would repay loans with interest calculated continuously through a real-time interest system.
- A single loan could be funded by contributions from multiple accounts.
- Interest terms would be negotiated individually with the contributors funding each loan.
